# DEJAVITTES BARBEARIA

Site institucional responsivo da DEJAVITTES BARBEARIA, feito em HTML, CSS e JavaScript em um único arquivo.

## Recursos
- Identidade visual preta e dourada inspirada na marca.
- Layout responsivo para celular e computador.
- Seções de serviços, Espaço Kids, apresentação, galeria e contato.
- Botões de agendamento que abrem conversa no WhatsApp.
- Link para o Instagram oficial.
- Menu mobile e botão flutuante de WhatsApp.

## Publicar na Vercel
1. Entre na Vercel e escolha **Add New → Project**.
2. Importe o repositório `diigopiress-a11y/DEJAVITTES-BARBEARIA`.
3. Como o site é estático e já tem `index.html` na raiz, não precisa de build command.
4. Faça o deploy.

## Antes de entregar ao cliente
- Substituir a marca tipográfica provisória pela logo oficial em arquivo de imagem.
- Substituir imagens ilustrativas por fotos reais da barbearia.
- Confirmar serviços, preços, endereço e horário de funcionamento.
- Testar os botões de WhatsApp em celular.
